02진술 분석 — 짚는 네 가지

전부 판정이 아니라 확인해 볼 지점. 근거(인용)가 없으면 담지 않는다.

표시무엇인용 규칙함께 나오는 것

미응답물었는데 다른 답이 온 곳질문·답 인용 2개확인 질문
확인 필요확인 가능한데 근거가 안 나온 주장(시간·장소·인물·금액)주장 인용 1개 이상물어볼 질문
태도 변화특정 주제에서 회피·화제 전환이 반복해당 지점 인용가리키기만

S5실시간 전사 — 배포됨

녹음 중 말하는 대로 화면에 자막이 뜨는 기능. 2026-09-02 배포 — Cloud Run iep-stream(Deepgram 주 + Google 백업).

있는 것

프론트 코드 완비

브라우저가 오디오를 16kHz PCM 으로 변환해 WebSocket 으로 보내는 코드(liveTranscript.ts)와 자막 UI 가 모두 있다.

배포됨

iep-stream 가동

iep-stream(Cloud Run · asia-northeast3)에서 WebSocket 게이트웨이 가동. Deepgram nova-2 주 · Google STT 백업. /health ok.

이제

자막 스위치 켜짐

VITE_STREAM_URL = wss://iep-stream…run.app. 녹음 화면에서 실시간 자막을 켤 수 있다.

켜려면(S5): ① stream-service 를 Cloud Run 에 배포(시크릿: worker 와 같은 JWT_SECRET, Deepgram 키 또는 Google 전용) → ② 나온 wss://…run.app 을 VITE_STREAM_URL 로 → ③ 웹 재빌드·배포. 그러면 자막 스위치가 나타난다. 실시간 코칭(25초)은 이와 별개로 이미 동작한다.

04§0 — 대전제

01 · 판정 안 함

거짓을 가리지 않는다

「거짓」·「신빙성」·점수를 매기지 않는다. 진위 판단은 수사관의 몫.

02 · 문장을 짚는다

사람이 아니라 발언

“이 사람이 거짓말한다”가 아니라 “이 두 발언이 어긋난다”.

03 · 인용 대조

지어낸 근거를 버린다

모델이 든 인용이 전사에 실제로 있는지 코드가 대조. 없으면 버림 — 서비스와 DB 두 겹.

04 · 다음 질문

확인할 것을 준다

지적에 그치지 않고, 다음에 물어 확인할 열린 질문을 함께.

05 · 참고 자료

강제하지 않는다

모든 산출은 참고 자료. 조서는 모델 없이 조립한 초안 — 제출 전 반드시 검토.
