로그인 제한최대 15분이메일 + IP 각각5회부터 지연. 계정을 잠그지 않는다 — 남의 이메일로 그 사람을 막을 수 있다

번들 이름 대조가 배포의 마지막 단계다. 2026-08-12 에 db push 만 성공하고 타입 검사가 실패해 프론트가 하루 동안 배포되지 않은 채였다. 그래서 배포는 올라간 번들 이름이 5분 안에 바뀌는 것까지 본 뒤에야 끝난다.

지금 알려진 문제

구현돼 있지만 고장난 것. 코드로 확인한 것만 적는다.

무엇증상
구간별 화자 ID 충돌조각마다 화자 번호가 새로 매겨지는데 합칠 때 이름표만 본다 — 다른 사람이 한 사람이 된다
전사 폴백이 조용하다화자 분리가 실패해 whisper 로 떨어져도 결과는 정상처럼 돌아온다
5xx 재시도 비대칭4xx 는 다시 시도하는데 5xx·타임아웃은 한 번에 포기한다. Workflow 재시도도 안 걸린다
transcribe_tries 리셋 없음세 번 실패하면 영구히 전사 불가. 다시 시킬 경로가 없다
등록 목소리 매칭실측 556개 중 5개에만 붙었다
R2 백업 401토큰이 Object 범위라 REST API 가 거절한다
