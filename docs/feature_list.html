딸린 것

  • 역할 기반 접근 — requireAuth · requireAdmin 미들웨어
  • 녹음 중 세션 만료 보호 — 화면을 옮기지 않고 배너만 표시, 녹음 계속
  • CORS 오리진 제한 — 허용 목록에 없으면 헤더를 주지 않음
  • 시드 비밀번호 제거 — 마이그레이션에 있던 admin1234·password123 을 난수 해시로

브라우저 쪽

  • 인앱 녹음 — 시작 · 일시정지 · 재개 · 완료
  • 파일 추가 — 여러 개, 녹음과 섞어서 가능
  • 자동 분할 (audioChunks.ts) — STT 입력 한도(23분 20초)를 넘는 오디오를 조각으로
  • 15초 백업 (recordingBackup.ts) — IndexedDB. 브라우저가 죽어도 최악 손실 15초
  • 세션 복구 — 다음 방문 시 못 올린 녹음을 찾아 다시 올릴 수 있음
  • 순차 업로드 큐 — 동시 전송으로 서로 밀리던 것을 하나씩
  • 탭 이탈 경고 — 녹음 중 창을 닫으려 하면 확인
  • 무음 마이크 감지 — 소리가 안 잡히면 알림
  • 동의 기록 — 녹음 전 고지·동의 확인. 켠 기능에 따라 문구가 달라짐

전사 관련 기능

  • 화자 분리 — gpt-4o-transcribe-diarize, 실패 시 whisper-1 로 폴백
  • 본인 목소리 등록 — 8초 클립으로 내 발화에 실명 표기
  • 화자 역할 판정 — 영업대표 / 고객 등을 LLM 이 추정
  • 미팅 노트 — 클로바노트 형식. 녹취 전체를 구간별로 나눠 요약(자르지 않음)
  • 발화 지표 — 역할별 발화수·턴·질문·발화시간·비율·WPM (코드 계산, LLM 아님)
  • 이전 미팅 맥락 — 같은 고객사의 직전 2건 요약을 함께 전달

L안전장치

  • 중복 STT 차단 — 조건부 update 잠금. 실측 동시 8개 중 1개만 통과
  • 죽은 잠금 회수 — 20분 지난 processing 은 죽은 것으로 간주
  • 분석 전 전사 대기 — 전사 미완 상태로 "제목만 분석" 되는 것을 방지
  • 미팅 삭제 시 오디오 전부 정리 — 원본 + 조각. 접두어로 찾음
  • 고정 키 재업로드 — 확장자가 바뀌어도 옛 파일을 남기지 않음
  • 소프트 삭제 — deleted_at. 복원 가능
  • 실시간 루프 세대 가드 — 껐다 켜도 루프가 둘로 늘지 않음
  • 업로드 메모리 절감 — File 을 그대로 R2 로 (Worker 한도 128MB)
아직 없는 것 (중요)

사용량 상한이 없습니다. v1 에는 있는데(일 20회/사용자, 50회/조직) v2 에는 아직입니다. STT 는 20분 오디오당 약 $1.27 이라, 분석 버튼을 반복해 누르는 것만으로 비용이 쌓입니다. 상용 전 1순위입니다 — docs/develop_plan.html 2단계.
