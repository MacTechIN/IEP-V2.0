#### **카드 컴포넌트 상세**

| 요소 | 구조 |
|------|------|
| **헤더** | 아이콘(20px) + 제목(14px, 700) + 상태 배지(12px) |
| **본문** | 정보 항목 (12px, 400, line-height: 1.5) |
| **액션** | 터치 영역(48px) - 아이콘 버튼 또는 링크 텍스트 |
| **여백** | 위/아래 12px, 좌/우 16px |
| **높이** | 100-180px (콘텐츠에 따라) |
| **반경** | 8px |
| **그림자** | 0 2px 8px rgba(0,0,0,0.1) |

#### **인터랙션**

| 동작 | 효과 |
|------|------|
| **카드 터치** | 상세 보기로 이동 (약 200ms 슬라이드 업) |
| **스크롤** | 부드러운 스크롤 (감속 50ms) |
| **상태 변화** | 페이드 인/아웃 (300ms) |
| **로딩** | 스켈레톤 로더 (회색 박스 애니메이션) |
| **알림** | 화면 상단 토스트 (3초 후 자동 소멸) |
