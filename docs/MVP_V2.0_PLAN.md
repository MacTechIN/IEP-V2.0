# MVP V2.0 마스터 계획서
**SEP(Sales Enablement Platform) UI/UX 완전 개편**

---

## 📊 Executive Summary

### **프로젝트 목표**
영업사원이 **미팅 직후부터 주간 리뷰까지** 모든 타이밍에서 **고객 니즈 기반 실무 정보**에 즉시 접근하고, 이를 다음 액션으로 바로 전환할 수 있는 **모바일-우선 플랫폼** 구축

### **핵심 개선**
| 항목 | V1 (현재) | V2.0 (목표) |
|------|---------|-----------|
| 진입 시간 | 앱 열어서 탭 여러 번 | 앱 열고 즉시 대시보드 |
| 정보 구조 | 리포트 중심 | 액션 중심 |
| 모바일 UX | 기능형 | 사용자 여정형 |
| PC 분석 | 단순 조회 | 심층 분석 + 학습 |
| 실행성 | 수동 정리 필요 | 자동 체크리스트 |

### **기대 효과**
- 🚀 영업사원의 미팅 후 생산성 **50% 향상**
- 📈 다음 미팅 준비 시간 **70% 단축**
- 💡 개인 성과 추적 **직관성 3배 개선**
- 🎯 액션 실행율 **80% 이상**

## 🛠️ 기술 스택

### **프론트엔드**
| 계층 | 기술 | 이유 |
|------|------|------|
| 모바일 | React Native | 크로스플랫폼 (iOS + Android) |
| 웹 | React 19 | 기존 v1과 동일 |
| 상태관리 | Redux Toolkit | 복잡한 상태 관리 |
| UI 컴포넌트 | Material-UI + Custom | 디자인 일관성 |
| 네이티브 모듈 | 커스텀 Objective-C/Swift | 알림, 카메라 등 |

### **백엔드**
| 계층 | 기술 | 이유 |
|------|------|------|
| API | Node.js + Express (기존) | 기존 v1 유지 |
| DB | PostgreSQL (기존) | 스키마 분리 (v1 / v2) |
| 캐시 | Redis | 성능 최적화 |
| 메시지큐 | RabbitMQ | 비동기 처리 |
| 알림 | Firebase Cloud Messaging | 모바일 푸시 |

### **DevOps**
| 항목 | 기술 |
|------|------|
| 배포 | Docker + Kubernetes |
| CI/CD | GitHub Actions |
| 모니터링 | Datadog |
| 에러 트래킹 | Sentry |
